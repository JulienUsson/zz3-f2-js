Ces exercices sont ceux de la séance : ils sont intercalés dans les [slides](/javascript-3/), juste après le concept qu'ils font travailler. Cette page les rassemble pour que vous puissiez les reprendre à votre rythme.

Vous pouvez coder directement dans les slides (les blocs de code sont exécutables), ou dans [CodeSandbox](https://codesandbox.io/s/vanilla) (fonctionne mieux avec Chrome/Chromium).

Chaque notion est vue **deux fois** : d'abord avec les prototypes (ES5), puis avec la syntaxe `class` (ES6+). C'est volontaire — les classes ne sont que du sucre par-dessus les prototypes, et vous croiserez encore du code ES5.

La documentation de Javascript est disponible [ici](https://developer.mozilla.org/fr/docs/Web/JavaScript) ou [là](https://www.w3schools.com/js/default.asp).
