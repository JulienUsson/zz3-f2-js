Ces exercices sont ceux de la séance : ils sont intercalés dans les [slides](/javascript-4/), juste après le concept qu'ils font travailler. Cette page les rassemble pour que vous puissiez les reprendre à votre rythme.

Vous pouvez coder directement dans les slides (les blocs de code sont exécutables), ou dans [CodeSandbox](https://codesandbox.io/s/vanilla) (fonctionne mieux avec Chrome/Chromium).

Les six premiers exercices sont courts : ils font manipuler une syntaxe chacun. Les sept suivants portent tous sur l'**immutabilité**, et montent en difficulté — c'est la notion qui compte le plus pour la suite du cours, parce que React repose entièrement dessus.

La documentation de Javascript est disponible [ici](https://developer.mozilla.org/fr/docs/Web/JavaScript) ou [là](https://www.w3schools.com/js/default.asp).
