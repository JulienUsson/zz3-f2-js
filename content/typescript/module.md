Ces exercices sont ceux de la séance : ils sont intercalés dans les [slides](/typescript/), juste après le concept qu'ils font travailler. Cette page les rassemble pour que vous puissiez les reprendre à votre rythme.

Les neuf premiers sont courts : ils font manipuler une notion chacun, directement dans les slides. Le dixième est le **mini-projet** de la séance — comptez l'heure de TP complète.

Nous utiliserons [CodeSandbox](https://codesandbox.io/p/sandbox/vanilla-ts) (fonctionne mieux avec Chrome/Chromium). Notez que les blocs de code des slides vérifient les types mais ne s'exécutent pas : Typescript ne s'exécute nulle part, il se compile.

La documentation de Typescript est [ici](https://www.typescriptlang.org/docs/), celle de Javascript [là](https://developer.mozilla.org/fr/docs/Web/JavaScript).
